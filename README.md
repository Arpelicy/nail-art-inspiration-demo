# 指尖灵感｜小红书 AI 上传材料

请保持以下文件结构，不要修改图片文件名：

```text
指尖灵感_轻量无内嵌图片版.html
预设图片包/
预设图片清单.md
给小红书AI的图片内嵌提示词.txt
```

## 本地预览

HTML 与“预设图片包”放在同一目录时，可直接打开 HTML 预览。轻量 HTML 已内嵌全部 CSS 与 JavaScript，但没有内嵌图片。

## 交给小红书 AI

上传轻量 HTML、所需图片与提示词文件；如果图片必须分批上传，严格按照图片清单顺序，并要求 AI 基于上一批输出继续处理。

## 注意

最终让 AI 重新内嵌全部图片后，文件大小仍会接近完整版。此材料的目的，是让平台先接收较小的 HTML 与独立图片，再在平台侧完成合并。
